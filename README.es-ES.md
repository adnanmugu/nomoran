

# Acerca de

Es una sencilla aplicación web para generar una serie de números de manera incremental. Su propósito es facilitarme la tarea de numerar papel NCR utilizado para formularios de pedido, ya que usualmente mis clientes me piden agregar un número a dichos formularios. Además, guarda automáticamente la secuencia generada en formato CSV o RTF, proporcionando una forma conveniente de imprimir o gestionar los números.

# Características

- Generación de números secuenciales
- Entrada de datos intuitiva
- Guardado automático
- Opciones de formato
- Minimización de errores
- Mejora de la eficiencia
- Personalización
- Procesamiento por lotes
- Acceso y gestión sencillos
